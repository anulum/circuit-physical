# Support

For questions about project scope, licensing or contributions, contact Miroslav Šotek, ANULUM, at protoscience@anulum.li.

The repository foundation is under construction. There is no released package, physical-implementation service, installation support commitment or qualified RTL-to-GDSII flow. Do not rely on planned records for a post-fill timing, IR-drop, electromigration, ESD, latch-up or mask-release decision.

For a technical report, provide the exact source revision, runtime environment, expected behaviour and minimal legally shareable input; never attach a customer design, a confidential foundry rule deck, proprietary IP views or a layout archive that is not public. Keep original outcomes and state which references or environments were unavailable. See [contributing](CONTRIBUTING.md).
